# Tabuada de 1 a 4

Programa em Java que exibe a tabuada dos números de 1 até 4, utilizando estruturas de repetição `for` aninhadas.

## Objetivo

Praticar:

- Estrutura de repetição `for`
- Laços de repetição aninhados
- Operações de multiplicação
- Uso de variáveis
- Exibição de resultados no console

## Funcionamento

O programa utiliza dois laços `for`.

O primeiro controla qual tabuada será exibida:

```java
for (i = 1; i <= 4; i = i + 1)
